# GitHubへ保存する範囲

このリポジトリは実装と再現手順を保存する。個人の利用記録や実行環境そのもののバックアップではない。ローカルファイルは削除・移動しない。

| 保存する | ローカルに残す |
|---|---|
| アプリ、音声診断、イベント診断のソース | APIキー・暗号化済みキー・環境変数ファイル |
| 自動テストと小さなランチャー | 実際に話した内容を含むJSONLログ |
| README、設計HTML、過去の調査資料 | 画面録画・スクリーンショット・音声 |
| 固定ベンチマークケースと既存の公開結果 | モデル重み・キャッシュ・仮想環境・依存ライブラリ |
| 依存関係の定義・セットアップ手順 | 個人用DB・ZIP・重複するローカル共有コピー |

今回、プロジェクト内の実装・ログ・キャッシュ・共有コピーをファイル名で確認した範囲ではDBファイルは見つかっていない（`.git`、`.venv`、`node_modules`等の内部は対象外）。現在の音声アプリはSQLite等ではなく `diagnostic_results/*.jsonl` への追記を使う。固定ベンチマークのJSONと個人の発話ログは別物。

`.gitignore` は今後追加されたファイルへの予防策で、すでに追跡されているファイルを消す機能ではない。公開前は追跡予定の一覧と内容を別途確認する。

新しいPCではPython環境を作り直し、必要な経路だけ依存関係／モデルを導入する。キーは自分のものを設定し、音声入力ショートカットとWindowsのサインイン時起動はそのPCで設定する。モデルやAPIの利用条件はそれぞれの提供元に従う。
